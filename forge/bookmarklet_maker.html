How to Use

Encode: Paste JavaScript in the left panel → Click "Encode →" → Get bookmarklet on the right. Drag the bookmark link above to your bookmarks bar.

Decode: Paste a bookmarklet URL in the right panel → Click "← Decode" → See the original JavaScript on the left.

Compression: Enable for large scripts to reduce URL length. Uses eval() to execute decompressed code (blocked by CSP).

CSP-Safe: Enable for sites with strict Content Security Policy that blocks eval(). Code is inlined directly. Choose compression OR CSP-safe, not both.

Minify: Remove whitespace and comments to reduce size. Works with CSP-Safe mode. Not as effective as gzip compression, but better than nothing.
